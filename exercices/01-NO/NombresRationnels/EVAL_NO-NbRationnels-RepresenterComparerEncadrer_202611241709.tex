\question[3]
Dans la fraction $\dfrac{3}{5}$, nomme les éléments suivants.

\vspace{10pt}
\begin{enumerate}[leftmargin=*,align=parleft, label=\alph*), itemsep=25pt]
\item Le nombre $3$ s'appelle le \sol{\;\bl}{numérateur}.
\item Le nombre $5$ s'appelle le \sol{\;\bl}{dénominateur}.
\item Le trait entre les deux nombres s'appelle la \sol{\;\bl}{barre de fraction}.
\end{enumerate}
